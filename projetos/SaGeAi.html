SaGeAi Hotéis

Desenvolvimento Web - HTML e CSS

O SaGeAi foi desenvolvido como um projeto de aprendizagem durante o curso de Front-end da Softex, reunindo em uma única experiência uma seleção de hotéis e informações sobre diferentes destinos. A proposta foi criar uma interface que tornasse a exploração das hospedagens mais visual e intuitiva.

Processo

O projeto foi desenvolvido durante uma bolsa de estudos da Softex, como parte das atividades do curso de Front-end. O desenvolvimento aconteceu em conjunto com outras duas integrantes do meu grupo, tornando o projeto também uma experiência de trabalho colaborativo.

A construção começou pela organização das informações que seriam apresentadas ao usuário. A partir disso, desenvolvemos uma página inicial com os hotéis selecionados, utilizando cards para apresentar suas principais informações de forma rápida e visual.

Também foram criadas páginas individuais para cada hospedagem, permitindo explorar diferentes detalhes sobre elas, como acomodações, gastronomia e principais atrativos. Para conectar todas essas informações, trabalhamos com múltiplas páginas e uma estrutura de navegação entre elas.

Na parte visual, utilizei HTML e CSS para estruturar e estilizar as páginas, trabalhando com imagens, cards, espaçamentos, efeitos de interação e responsividade. O projeto foi uma oportunidade importante para colocar em prática os conceitos de Front-end aprendidos durante o curso.
